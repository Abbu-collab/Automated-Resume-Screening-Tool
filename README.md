# Automated Resume Screening Tool

## Overview

This project is an AI-powered Resume Screening Tool developed using Python.

The system:
- extracts resume text
- compares resumes with job descriptions
- calculates matching scores
- ranks candidates
- generates shortlist reports

---

## Features

- PDF Resume Parsing
- DOCX Resume Parsing
- NLP-based Matching
- TF-IDF Scoring
- Cosine Similarity
- CSV Report Generation
- Streamlit Dashboard

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- PyPDF2
- python-docx
- Streamlit
